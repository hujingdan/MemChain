# 时光容器：珍藏每一段不可复制的人生故事

—— ***让数据成为记忆的画笔，让你成为自己故事的观众***

我们总在刷短视频里看别人的人生片段，却常常忘了：自己的每一次欢笑、每一段旅程、每一句走心的笔记，都是值得被好好安放的珍贵故事。当照片散在相册、录音藏在文件夹、笔记落在不同 APP，那些鲜活的记忆便会慢慢褪色~

于是，有了这个「时光容器」—— 它不只是一个数据管理工具，更是为你的人生体验打造的 “私人博物馆”：

### 🌟 我们想帮你做三件事

##### * **把散落的记忆 “聚” 起来**

> 像一个安全的私人保险箱，收纳你的照片、录音、文字笔记，支持本地存储或可控云加密，从源头守护数据隐私，再也不用在各个平台间来回寻找。

##### * **让沉默的数据 “活” 起来**

> 借助本地 + 安全云端 AI，帮你读懂数据里的故事：提取笔记里的关键事件、识别录音 / 文字中的情绪起伏、发现藏在日常里的规律（比如 “每年春天都去看樱花”），让你更懂自己的人生轨迹。

##### * **用喜欢的方式 “展” 出来** 

不只是简单陈列，更是艺术化的表达：

* 「时光流」：用智能时间轴串联所有记忆，按情绪、人物、标签快速找回某一刻；
* 「AI 策展助理」：说一句 “展示 2023 年和家人的温馨时刻”，就能生成专属电子相册；
* 「记忆调色盘」：把照片调成油画、水彩或情绪专属色，让记忆有你喜欢的模样；
* 「主题博物馆」：为大学时光、闺蜜旅行、职场成长建一个沉浸式空间，漫游式重温那些重要阶段。

### 🔒 我们始终在意的

所有敏感分析（如私密日记情感图谱）仅限本地处理，数据是否上云、是否分享，全由你掌控 —— 因为最珍贵的人生故事，该有最安心的存放方式。

每一段体验都不该被辜负，每一份记忆都值得被好好珍藏。

这里，是属于你的「人生故事展览馆」，也是对抗遗忘的温柔力量。

欢迎体验、提出想法，或与我们一起完善这个 “时光容器”～
